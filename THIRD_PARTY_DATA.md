# Data attribution

Municipality boundaries originate from ISTAT and geojson-italy, formerly
openpolis/geojson-italy, now https://github.com/guglielmo/geojson-italy .
The upstream data are distributed under CC BY 4.0. The archived representative
points and a small test fixture are derived from the author-supplied inputs.
Keep this attribution when redistributing derived data.

The original municipality-selection algorithm is not included; fixed selected
coordinates are provided. Downloaded boundaries may change over time and must
not silently replace these archived inputs.

The authors must choose the code license and confirm data-release permissions
before making the repository public. No license is assigned by this cleanup.
